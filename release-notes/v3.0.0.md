PortAtlas 3.0.0 is the new name of NetFlowAudit. The audit, the exports and the map behave as in 2.0.3, but the executable, the default configuration file and the repository address change: read the [upgrade guide](https://github.com/curvecoder/PortAtlas/blob/main/docs/how-to/upgrade-to-3.0.md) before updating a service or a scheduled task.

## Breaking changes

- **The executable is renamed**: `PortAtlas.exe` on Windows and `PortAtlas` on Linux, instead of `NetFlowAudit.Cli.exe` and `NetFlowAudit.Cli`. The archives are named `PortAtlas-3.0.0-win-x64.zip` and `PortAtlas-3.0.0-linux-x64.tar.gz`.
- **The default configuration file is `portatlas.json`**, instead of `netflowaudit.json`. An existing `netflowaudit.json` is not read: rename it, or pass its path with `--config`.
- **The repository moves** to `https://github.com/curvecoder/PortAtlas`. The old address redirects to it.
- The `CLI Command` section of the HTML map now proposes `PortAtlas map …`.

## Fixes

- HTML map: arrow labels no longer overlap each other, and server boxes no longer hide them.
- `--obfuscate` now displays `HOMELAB-01` and `192.168.1.10` instead of server fleet names.

## Documentation

- The README and the guides describe a home lab instead of a server fleet, and the topology map screenshot shows one.
- New guide: upgrade from 2.x to 3.0.
