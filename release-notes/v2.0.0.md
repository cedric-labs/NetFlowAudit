NetFlowAudit 2.0.0 replaces the 1.x options with commands and fixes several recording and export defects. The 1.x command lines are rejected: read the [upgrade guide](https://github.com/curvecoder/NetFlowAudit/blob/main/docs/how-to/upgrade-to-2.0.md) before updating a service.

## Breaking changes

- **Commands instead of options**: `audit`, `map`, `export rules`, `export ndjson`, `resolve`, `lookup <ip>`, `config init`. Each command accepts only its own options; an unknown option, a removed 1.x flag or a value outside the accepted list is an error with exit code 1.
- **Started without a command, the program prints the help and exits with code 0.** Services and scheduled tasks must run `audit --no-tui --config <path>`.
- `--isolated` and the `IsolatedMode` key are removed. Use `audit --no-rdap` (no Internet RDAP query, reverse DNS kept), `audit --no-dns`, or `resolve --cache-only`. A configuration file with `"IsolatedMode": true` stops the program until it is replaced by `"ResolveIpOwners": false`.
- `-i/--input` replaces `--inputs`, `--input-dir` and `--input-filter`: it is repeatable and accepts a file, a directory or a wildcard pattern.
- `export rules --zone internal|public|all` replaces `--internal-only`, `--public-only` and `--destination-zone`.
- `ExcludeSystemAccounts` now defaults to `false` (see the account fix below).

## Fixes

- The `UserName` column was always empty: the account of each process is now recorded (process token on Windows, `/proc` and `/etc/passwd` on Linux).
- `export rules --listeners-only` always produced an empty matrix; listening services are now exported as inbound rules from any source.
- `config init` and the `netflowaudit.json` shipped in the archives contained sample values that changed what was recorded, such as `ExcludedRemoteIps: ["192.168.1.50", "10.0.0.0/8"]`; they now hold the built-in defaults.
- The `CLI Command` section of the HTML map copies the 2.0 `map` syntax.
- File name tokens of the configuration file are expanded for every command.

## Documentation

The documentation is rewritten in English and French: a tutorial, how-to guides, a reference organised by command with the option matrix, and an explanation of how the agent works. It is checked against the code by the build pipeline.

## Shared frameworks

- ProcessForge 1.1.0: account of each process.
- TopologyForge 1.5.0: configurable syntax of the copied CLI command.
