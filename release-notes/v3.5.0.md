PortAtlas 3.5.0 groups public addresses on the topology map. Existing commands, configuration files and outputs behave as in 3.4.0, except that public IPv4 addresses no longer get one zone per /24.

## Improvements

- **One "Internet" zone**: in the Draw.io diagram and in the HTML map (subnet sort), every public IPv4 address is placed in a single "Internet" zone instead of one zone per /24 subnet. Private, loopback, link-local, shared (100.64.0.0/10), multicast and reserved addresses keep their /24 zones.

## Dependencies

- FileForge.Core 1.1.1, ProcessForge 1.1.2, SocketForge 1.1.1, TopologyForge 1.11.0.
