PortAtlas 3.2.0 makes the `tree` + `bus` topology map easier to read on large networks. Existing commands, configuration files and outputs behave as in 3.1.0.

## Improvements

- **Merged bus arrivals** (`--routing bus`): the branches that reach a server through the same side and in the same direction end under a single arrow head, instead of one head per source.
- **More compact `tree` layout** (`--layout tree`): large maps use more columns per row (about the square root of the server count, at least 4 above 9 servers), and the gaps between the root row and the subnet bands follow `--spacing` instead of fixed values, so the map is much less tall.
- **Tighter rows without port labels** (`--edge-labels none`): stacked rows keep a 24 px gap instead of 42 px, and toggling *Show Ports* on the HTML map recomputes the layout.

## Dependencies

- TopologyForge 1.7.0.
