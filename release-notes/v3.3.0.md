PortAtlas 3.3.0 continues the work on the readability of the topology map. Existing commands, configuration files and outputs behave as in 3.2.0.

## Improvements

- **Bus branches around tree rows** (`--routing bus`): when the straight descent to a server would cross the boxes of the rows in between, the branch now runs down the corridor next to the target and reaches it through the gap just before it. Port labels stay clear of these detours.
- **Tighter tree rows** (`--layout tree`): rows are stepped from a smaller base, which leaves 49 px between two boxes with the `balanced` spacing instead of 64 px.
- **Horizontal tree aligned on the tree layout**: subnet bands wrap and spread like the vertical tree.
- **Closer subnet zones**: the gap between subnet clusters follows `--spacing`.

## Other changes

- Code comments, log messages and console output of the shared frameworks are now in English.
- Rebuilt binaries no longer embed local build paths.

## Dependencies

- FileForge.Core 1.1.1, ProcessForge 1.1.2, SocketForge 1.1.1, TopologyForge 1.9.1.
