PortAtlas 3.4.0 adds a way to draw the Draw.io topology diagram without subnet zones. Existing commands, configuration files and outputs behave as in 3.3.0.

## Improvements

- **Draw.io without subnet zones** (`--drawio-subnets off`, or `DrawioSubnets` in `portatlas.json`): hosts are laid out in a grid instead of being grouped by subnet. The default, `on`, keeps the previous diagram.
- **Wrapped subnet zones**: in the Draw.io diagram, zones wrap onto several rows instead of extending into one very wide row.
- **Copied command**: the command copied from the HTML map always includes layout, sort, routing and spacing.

## Dependencies

- FileForge.Core 1.1.1, ProcessForge 1.1.2, SocketForge 1.1.1, TopologyForge 1.10.0.
