NetFlowAudit 2.0.3 fixes the executables of versions 2.0.0 to 2.0.2, which stopped as soon as an audit started. Users of these versions should replace their executable.

## Fixes

- `audit` stopped at startup with `FileNotFoundException: Could not load file or assembly 'ProcessForge, Version=1.0.2.0'`. The shipped ProcessForge library carried a lower assembly version than the one SocketForge asks for, so the runtime refused to load it. The libraries now carry their full version, and a test checks that every shipped library matches the versions the others ask for.

## Release process

- Each Windows executable is now started with a short audit before it is published. A release stops if the executable exits instead of auditing.
