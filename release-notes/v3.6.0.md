PortAtlas 3.6.0 adds a graphical interface for Windows. The command line, its options, configuration files and outputs behave as in 3.5.0, with two additions listed below.

## New

- **Graphical interface** (`PortAtlas.Gui`, Windows x64, separate download): the form of each command is generated from the command tree of the CLI, so every command and option is available with its help text. It shows the resulting command line (with a copy button), runs the command and streams its output, supports the system, light and dark themes, and folds the option groups.
- **Profiles**: a profile stores the form of every command and the path of `PortAtlas.exe`. Profiles and preferences are saved in the `Data` folder next to the executable; profiles found in `%APPDATA%\PortAtlas` are copied there on first start. When the folder cannot be written, the GUI keeps using `%APPDATA%\PortAtlas`.
- **Explained choices**: each accepted value of a choice option (`--layout`, `--sort`, `--routing`, ...) is described in the drop-down list and under the field.

## Improvements

- **Draw.io server order** (`--sort`): the sort method now also orders the servers and zones of the Draw.io diagram.
- **Shell completion**: the accepted values of choice options are offered as completions.

## Fixes

- A process that cannot be started is reported by the GUI instead of escaping the run command.

## Dependencies

- FileForge.Core 1.1.1, ProcessForge 1.1.2, SocketForge 1.1.1, TopologyForge 1.12.0. The GUI uses Avalonia 11.3.22.
