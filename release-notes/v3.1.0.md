PortAtlas 3.1.0 adds a pair matrix to the firewall rule export and new options to lighten busy topology maps. Existing commands, configuration files and outputs behave as in 3.0.0.

## New features

- **Pair matrix**: `export rules --pairs-output <path>` also writes one row per source and destination address, with the merged rule count, the distinct ports and the observation span. The two directions between two servers stay on two rows. See the [pair matrix columns](https://github.com/curvecoder/PortAtlas/blob/main/docs/reference/output-formats.md#pair-matrix).
- **`bus` arrow routing** (`--routing bus`, `MapRoutingMode`): the arrows of a server share one trunk per direction, then split into one branch per target. Designed for the `tree` layout.
- **Arrow labels** (`--edge-labels ports|none`, `MapEdgeLabels`): `none` unchecks *Show Ports* on the HTML map. Arrows lose their port labels and the flows of a server pair are merged into one arrow, with a head at each end that receives a flow. The server inspector still lists the ports, and the copied CLI command keeps the option.
- **One Draw.io edge per server pair** (`--drawio-edges pair`, `DrawioEdgeMode`): the Draw.io diagram draws a single edge between two servers, with two heads when flows go both ways.

## Dependencies

- TopologyForge 1.6.0.
