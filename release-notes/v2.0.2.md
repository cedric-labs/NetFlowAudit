NetFlowAudit 2.0.2 fixes several problems of the interactive HTML topology map and lowers the memory used by `export ndjson`.

## Fixes

- Topology map: host and process names were written into the server inspector without escaping. A reverse DNS name containing HTML could run a script in the page when the server was clicked. Every value is now escaped, and the data embedded in the page can no longer close its script block.
- Topology map: the port filter fields read `8000-8080` as port 8000 only. A port range given with `--include-ports` or `--exclude-ports` was therefore cut down as soon as the map opened. Ranges are now applied in full.
- Topology map: a search that matched a server showed that server alone, without any arrow. It now shows the server, its direct neighbours and the flows between them. The search also matches the port and process of each flow, so an outbound client process such as `curl` can be found.
- Topology map: in the `tree` and `horizontal-tree` layouts, a search with no result raised a script error and left the previous servers on screen.
- Topology map: two flows exchanged in opposite directions between the same pair of servers were bent to the same side. They are now drawn on either side of the pair.
- Topology map: the header counters showed the servers of the current page instead of the whole filtered result, and the service port counter ignored the filters. `Reset` now also refreshes the displayed CLI command.

## Performance

- `export ndjson` reads the CSV files one after another and keeps only the current file in memory, instead of loading every entry of every file before writing.
