# Upgrade from 1.x to 2.0

NetFlowAudit 2.0 replaces the 1.x options with commands. The 1.x command lines are rejected; update scripts, scheduled tasks, services and units before deploying 2.0.

## Services and scheduled tasks

A 1.x service started the audit without arguments, or with `--daemon` / `--no-tui`. In 2.0, the program started without a command prints the help and exits with code 0. Change the arguments to:

```text
audit --no-tui --config <path>
```

## Command correspondence

| 1.x | 2.0 |
| :--- | :--- |
| *(no option)* | `audit` |
| `--daemon`, `--no-tui`, `--silent` | `audit --no-tui` |
| `--isolated`, `--offline`, `--no-ip-owners`, `--resolve-ip-owners false` | `audit --no-rdap` |
| `--resolve-dns false` | `audit --no-dns` |
| `--map-only -i <file>` | `map -i <file>` |
| `--map <path>` | `audit --html <path>` or `map --html <path>` |
| `--export-drawio <path>`, `--drawio <path>` | `map --drawio <path>` |
| `--input-dir <dir> --input-filter <pattern>` | `-i "<dir>/<pattern>"` |
| `--inputs a.csv,b.csv` | `-i a.csv -i b.csv` |
| `--map-layout`, `--map-sort`, `--map-routing`, `--map-spacing` | `--layout`, `--sort`, `--routing`, `--spacing` |
| `--drawio-edge-mode` | `--drawio-edges` |
| `--export-rules <path>` | `export rules -o <path>` |
| `--internal-only`, `--public-only`, `--destination-zone <zone>` | `export rules --zone internal` or `--zone public` |
| `--exclude-ephemeral` | default behaviour; `--include-ephemeral-ports` keeps them |
| `--export-ndjson <path>` | `export ndjson -o <path>` |
| `--ndjson <path>`, `--output-ndjson <path>` | `audit --ndjson <path>` |
| `--resolve-offline` | `resolve` |
| `--resolve-offline --isolated` | `resolve --cache-only` |
| `--caches a.json,b.json` | `resolve --cache a.json --cache b.json` |
| `--test-ip <ip>`, `--lookup <ip>` | `lookup <ip>` |
| `--init-config`, `--generate-config` | `config init` |
| `--anonymize` | `audit --obfuscate` |
| `--obfuscate-server`, `--obfuscate-ip` | `audit --mask-server`, `audit --mask-ip` |
| `--history-limit` | `audit --reload-history` |
| `--aliases` | `audit --alias` (repeatable) |
| `--exclude-remote-ip` | `audit --exclude-remote-ips` |

Short aliases of filter options (`--exclude-host`, `--include-port`…) are removed; use the plural forms. Values outside the accepted lists, such as `--direction listening` or `--layout force`, are rejected.

## Configuration file

| Change | Action |
| :--- | :--- |
| `IsolatedMode` removed | Replace `"IsolatedMode": true` by `"ResolveIpOwners": false`; with `true`, 2.0 refuses to start |
| `config init` writes the defaults | Files generated by 1.x contained sample exclusions (`ExcludedRemoteIps: ["192.168.1.50", "10.0.0.0/8"]`, `ExcludedLocalPorts: [22, 3389]`…). Review them: they stop the recording of those flows |

## HTML maps

Maps generated by 1.x copy a 1.x command from their `CLI Command` section. Regenerate them with 2.0 to get the `map` syntax.
